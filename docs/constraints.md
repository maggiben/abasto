# Constraints & Non-Negotiables

- Must work offline-first (local network capable)
- Must support keyboard-only POS operation
- Must run on low-resource hardware (Raspberry Pi)
- Must minimize disk writes
- Must not rely on cloud services
- Must be modular and extensible
- Must support CSV import/export
- Must support ESC/POS printers via USB
- Must use next version 16 or higher
